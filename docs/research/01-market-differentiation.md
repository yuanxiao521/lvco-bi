## 0. 结论先行（TL;DR）

### 0.1 一句话定位
**大厂卖"云上按年租的 BI"，开源卖"要自己搭的 SQL 生成器"，我们卖"装进你自己电脑、连你自己数据库、带治理和交付物的一人公司 BI"。**

### 0.2 三个决定（我的建议，均为〔推断〕，理由见第 3、4、5 节）

| 决定 | 建议 | 关键理由（证据锚点） |
|---|---|---|
| **卖什么** | 主力卖 **B「代部署 + 陪跑」**，用 **A「成品部署包」** 做引流和低价入口；**坚决不卖源码** | 源码市场是 300–700 元的"半成品"价格锚，卖源码等于自降身价且必然被盗版；大厂企业版首年 5,888–108,000 元，中间有巨大的"人工交付"空档 |
| **卖多少钱** | A 包 **699 元**（区间 399–1,299）／B 服务 **2,800 元**（区间 1,500–4,999）／C 教学版 **299 元**（区间 199–499，批改 +199） | 腾讯云 BI 个人版 550 元/年〔事实〕、九数云 5,888 元/年起〔事实〕、源码 300–700 元〔事实〕、慕课网同类体系课 1,199 元〔事实〕 |
| **课怎么排** | **10 章必修 + 2 章选修**，每章"目标→实验→可交付作业→产品内操作路径"，卖点是**"每人一套能跑的环境 + 可验收作业"**，不是讲知识 | 慕课网体系课 ¥1,199 是视频为主〔事实〕；B 站同类基本免费〔推断，基于搜索结果的普遍形态〕。我们没有讲师流量，只能靠"环境 + 验收"差异化 |

### 0.3 最值得记住的三件事
1. **大厂的 AI 分析能力被锁在贵套餐里**：Power BI Copilot 要求付费 Fabric 容量 F2+ 或 Premium P1+，试用容量和免费 SKU 不支持〔事实〕；腾讯云 BI 基础版 7,225 元/年/10 用户、专业版 108,000 元/年/50 通用用户〔事实〕。→ **"不用买容量"本身就是卖点。**
2. **纯 AI 分析工具连不上你的生产库**：ChatGPT 数据分析的 Python 环境"不能发起外部网络请求或 API 调用"，必须先上传数据〔事实〕。→ **"直接连你自己的 MySQL/PG、密码不过浏览器"是硬差异。**
3. **大厂 AI 分析的前置成本是"人"**：Cortex Analyst 要先写 Semantic View（YAML 语义模型）〔事实〕；Databricks Genie Agents 要配 Unity Catalog、示例 SQL、指令和信任资产〔事实〕。→ **"开箱即用、0 语义建模"是第三块空地。**

### 0.4 我最不确定的两点（先说在前面）
- **闲鱼站内价格我没拿到**：goofish.com 搜索页只返回 JS 壳（页面文本仅"二次元"），小红书/淘宝同理。文中所有"电商侧价格带"都来自**互站（源码交易平台）**这个替代证据，并明确标注。〔推断部分已标出〕
- **快照日期异常**：抓 Tableau/Power BI 官方页时，页面返回的 modified_date 出现 2026 年（如 Tableau 定价页 modified 2026-10-20、Power BI Copilot 文档 ms.date 2026-08-24）。我按"页面自报日期"引用，未做独立核实，**如果这些日期不可信，请以你本地看到的页面为准，结论方向不受影响**。

### 1.4 电商侧：闲鱼/淘宝的"BI 源码 / 数据大屏 / AI 数据分析"商品形态

**先说结论：闲鱼、淘宝的站内商品价格我没查到。** goofish.com 搜索页返回的是 JS 壳（抓到的正文只有"二次元"两个字），淘宝同理需要登录；小红书上能找到相关讨论帖（如"99 卖 1400？🐟骗子""避雷"类），但**帖文正文我未取到可引用的价格数据**。所以下面用**互站（huzhan.com，源码交易平台）**做替代证据，并明确标注它与闲鱼的关系是"同类商品、不同渠道"。

**〔事实〕互站平台侧数据：**
- 源码集市当前共 **92,812 个源码商品**（来源页实时显示）。
- 典型"数据大屏/BI 驾驶舱"商品的规格字段是：**规格=整站源码、授权=需要授权 / 免授权、源文件=完全开源（含全部源文件）**。
- 价格带示例（同页抓到的真实标价）：**300.00 元 / 500.00 元 / 700.00 元**（如"AI 导航站源码"300 元、"多语言承兑系统"500–700 元）。**BI/大屏类商品的价格在页面上是 JS 异步加载，我没取到具体数字**，但同页的价格档位显示源码市场的主流成交带在**数百元级**。
- 平台的交易/纠纷规则（对我们设计交付物极有参考价值）：源码默认交易周期 1 天（手动发货 3 天），买家可延长 3 天；**可判退的情形包括**：描述（含标题）与实际源码不一致（如描述 PHP 实际 ASP、功能缺失、版本不符）、有演示站但与实际差异 >5%、卖家未发货、承诺免费安装却未履行；**平台明确不对"永久包更新""永久技术支持"这类售后承诺做担保，请买家自行鉴别**；平台对交易过程与商品快照永久存档。

**〔推断〕据此判断电商侧形态与价格带：**

| 形态 | 典型描述 | 价格带（推断） | 依据 |
|---|---|---|---|
| 纯源码包（半成品） | "数据大屏源码/BI 驾驶舱源码，ThinkPHP/Vue，30+ 组件，需自行部署" | **200–800 元** | 互站同页价格档位 300/500/700 元；平台明确"需授权/免授权"二分 |
| 模板/大屏素材包 | 单套大屏模板、组件库 | **50–300 元** | 与源码包价格梯度关系〔推断〕 |

**这个市场的三个特征（对我们的打法直接有影响）**〔推断，但每条都能从上面的平台规则推出来〕：
1. **买家预期是"便宜 + 源码 + 一次性"**：所以卖"部署包 + 许可"必须在商品标题里就把"不含源码"说清，否则差评和纠纷率会失控。
2. **平台只保"描述一致"，不保"以后一直好用"**：所以我们**不要承诺"永久更新"**，改成"1 年内更新通道"，这既符合平台惯例也保护自己。
3. **半成品是主流供给**：买家真正痛的是"装不上、跑不起来、没人管"。**我们的溢价必须建立在"装得上 + 跑得起来 + 有人回话"**，这三件事才是 699 元 vs 300 元的理由。

## 2. 三条"它做不到、而我们能"的空隙

> 每条都写成三段：**对手为什么做不到（带证据）→ 我们凭什么做到（带代码位置）→ 怎么变成卖点话术**。这一节是整份文档的商业核心。

### 空隙一：「能连你自己的生产库、密码还不流出去」——通用 AI 分析工具根本做不到

**对手为什么做不到**〔事实〕
- **ChatGPT 数据分析**的 Python 沙箱：官方 help 原文说"用于数据分析的 Python 环境**不能发起外部网络请求或 API 调用**。如果分析依赖外部数据，请先上传数据或连接可用数据源后再提问"。也就是说它的模型是"你把文件交出来，我在我的沙箱里算"。
- **Power BI Copilot**：必须先有付费容量（F2+/P1+），试用容量和免费 SKU 不支持；且必须先把语义模型"为 AI 准备好"，否则"Copilot 可能误解数据、给出泛化或不准的结果"。
- **Snowflake Cortex Analyst**：必须先写 Semantic View（YAML）——表名、列名、取值类型、描述、指标、关系、已验证问法，一样都不能少。**中小商家没有这个人。**
- **Databricks Genie Agents**：需要 pro/serverless SQL warehouse + Unity Catalog + 示例 SQL + 指令 + 信任资产，且配置权限"一般限于管理员"。

**我们凭什么做到**〔事实：本仓库代码〕
- 凭据**加密落库**：AES-256-GCM 版本化信封（lvco-bi/backend/app/utils/crypto.py，config.py 有专门的"数据源凭据加密"段）。
- **密码不进 DuckDB catalog**：连接走 "CREATE SECRET + ATTACH" 两条语句（lvco-bi/backend/app/connectors/attach_sql.py、duckdb_client.py），密码在 SECRET 里，不进连接串、不出现在 catalog。
- **服务端凭据引用**：支持 env:/file: 形态，密码可以根本不经过浏览器（lvco-bi/backend/app/services/credential_refs.py）。
- **敏感列治理**：agent_tools.py 里对敏感列的处理是"**只告诉模型『存在且不可用』，不给样例、也不放进可查询列**"——这是很硬的一条，很多开源项目连概念都没有。
- **一份凭据多张表**、TLS（含 verify-full/CA）、连接健康检查与轮换（connection_service.py 里明确写了凭据"落库形态与生命周期（轮换）"）。

**卖点话术（可直接放闲鱼详情页）**
> "AI 分析工具要么让你把 Excel 上传到它服务器，要么先交一年容量费。我们装在你自己的电脑/服务器上，直接连你自己的 MySQL/PostgreSQL——**密码加密存在本地、连 DuckDB 的 catalog 里都不会留**，还能指定『哪几列不许给 AI 看』。数据一步都不出你的机器。"

### 空隙二：「指标口径 + 血缘 + 定时洞察」这套治理，大厂绑在 5,888–108,000 元/年的套餐里

**对手为什么做不到**〔事实〕
- **腾讯云 BI**：基础版 **7,225 元/年/10 用户**、专业版 **108,000 元/年/50 通用用户**。
- **九数云**：**5,888 元/年**（1 编辑 + 5 查看）起，另一档 **13,888 元/年**。
- **Power BI Copilot**：要 F2+/P1+ 付费容量。
- **帆软 FineBI / 观远 / 永洪 / SmartBI**：全部"报价咨询/商业授权 + 实施"，**不公开价格**——意味着中小客户连"多少钱"都问不到，且采购周期长。

**我们凭什么做到**〔事实：本仓库代码〕
- **指标中心 + 指标血缘 + 版本**：指标 API 有 /metrics/{id}/dependencies（血缘依赖/下游/影响）与 /metrics/{id}/lineage（字段级血缘），见 lvco-bi/backend/app/api/v1/metrics.py 与端到端脚本 scripts/_live_e2e_metric_flow.py 的覆盖范围。
- **洞察引擎**：app/services/insight_engine/ 下有 scheduler（定时），并把洞察结果自动生成日报 Report（alembic 迁移 0012 新增 ai_insight 枚举、0016 加 last_refreshed_at 用于洞察/报告触发）。
- 仪表盘/画布/报表/通知齐全，形成"指标→洞察→报告→推送"的闭环。
- 规划中的数据体检 + 数据清洗（9 类算子 + 干跑 + 派生数据源）让"脏数据进不来"也变成产品的一部分。

**〔推断〕为什么这是空隙**：中小商家真正的痛不是"没有图表"，而是**"两个数对不上、不知道信哪个"**（FineBI 官网自己就用"两位高层汇报差 1 亿销售额"当开场案例）。而血缘 + 版本 + 口径，恰好是大厂用来收年费的那部分能力。**我们把这块做成单机版，等于把"贵的部分"单独拆出来贱卖——这是我们最锋利的刀。**

**卖点话术**
> "两个数对不上？我们的指标中心每个指标都有口径、有版本、有血缘——点一下就知道这个数是从哪张表、哪一列、经过哪几步算出来的。这套东西在云 BI 里是专业版才有的功能。"

### 空隙三：「交付物 + 售后 + 可审计」——开源 Agent 和源码贩子都不提供

**对手为什么做不到**〔事实〕
- 开源项目（WrenAI / Vanna / DB-GPT / PandasAI / Chat2DB）交付的是**代码仓库**，不是**可运行的业务闭环**，更不含"指标口径/权限/售后"。
- 源码市场（互站）的规则白纸黑字：**平台不对"永久包更新""永久技术支持"做担保，请买家自行鉴别**；可判退的情形之一是"描述的功能实际缺少"。**换句话说：这个市场的默认预期就是"买完自生自灭"。**

**我们凭什么做到**〔事实 + 推断〕
- 事实：产品已具备"人对结论负责"所需的痕迹——敏感列不进可查询列（agent_tools.py）、指标血缘可下钻到字段（/metrics/{id}/lineage）、洞察结果自动落到 Report 留档（ai_insight 枚举）、凭据有轮换生命周期（connection_service.py）。
- 〔推断〕我们真正的商品不是软件，是**"装好 + 跑通 + 有人回话"**。这也是唯一能让 699 元比 300 元源码贵得有理、并且挡得住退款的东西。

**卖点话术**
> "别人卖你一堆源码，装不上自己扛。我们卖的是：**安装脚本 + 演示库 + 3 个行业模板 + 30 天答疑 + 更新通道**。跑不起来，我远程给你装。"

## 3. 我们可以抄的 5 个具体机制（能直接进设计文档，不是口号）

> 每条都写清：抄谁 → 抄什么 → 落到我们的哪个模块/字段/交互 → 验收标准。

### 机制 1｜指标订阅 + 三段式 Digest（抄 Tableau Pulse）
- **抄什么**：Tableau Pulse 的链路是"建指标定义 → 用户 Follow → 通过邮件/Slack 收 digest → 点开做洞察探索"，digest 里含当前值、与前期的百分比变化、已应用的过滤条件与洞察〔事实〕。
- **我们怎么做**：指标中心加"关注"（follower 表：metric_id, user_id, 保存的时间窗/过滤器）；复用现有 insight_engine.scheduler 每日跑一次，产出固定三段卡片：**① 当前值 ② 对比（环比/同比 + 方向） ③ 一句话解释（为什么变，来自归因规则）**；走现有通知渠道。
- **验收**：任意指标点"关注"后，次日 09:00 收到三段式卡片；点卡片能跳到该指标的血缘图。

### 机制 2｜语义模型 + 已验证问法库 + 评测集（抄 Snowflake Cortex Analyst）
- **抄什么**：Cortex Analyst 靠 Semantic View(YAML) 定义业务概念/指标/关系，配套 **Verified Query Repository**（样例问题 + 其 SQL 答案）和 **Evaluations**（评测）来提精度〔事实〕。
- **我们怎么做**：在指标表上挂两个子表——verified_questions（标准问法 + 标准 SQL/口径 + 创建人）、evaluation_cases（问题 + 期望结果/期望指标）；对话助手在路由前先检索 verified_questions，命中就直接复用并标注"**已认证问法**"；提供"跑一遍评测集 → 输出命中率"的离线按钮（就 20 题也行，关键是可回归）。
- **验收**：新产品上线后，评测集命中率作为发布门槛（例如 ≥85% 才允许发版）。

### 机制 3｜信任资产 + 用终端用户自己的权限取数（抄 Databricks Genie Agents）
- **抄什么**：Genie Agents 用"示例 SQL + 指令 + 信任资产"喂养，关键设计是 **compute 凭据嵌在 Agent 里，但"数据访问始终按每个终端用户自己的权限来评估"**〔事实〕。
- **我们怎么做**：数据源/Agent 配置里加"信任资产"分组（示例问题、示例 SQL、业务规则说明、口径说明）；执行链路上**取数用服务端凭据（已有 env:/file: 引用），但结果集按当前登录用户的行/列权限再过滤一遍**，并写审计日志（谁问的、命中哪条信任资产、扫了哪些表、返回多少行）。
- **验收**：同一问题，A 用户和 B 用户看到不同行数；审计日志能还原一次问答的完整链路。

### 机制 4｜AI 产出必须落在"可被人接手"的产物里（抄 Hex）
- **抄什么**：Hex 的核心不是"AI 给答案"，而是"AI 的答案留在 notebook 里，你可以继续改、再发布成 app"；官方说法是 notebook agent 直接产出可用 SQL 并支持在 notebook 内连续编辑〔事实〕。
- **我们怎么做**：对话助手的每一步产出一律落成"画布上可编辑的对象"（图表/查询步骤/派生指标），并提供"**从这一步继续手工编辑**"按钮；画布助手与对话助手共享同一份步骤模型（这个我们架构上本来就该做）。
- **验收**：任何一个对话生成的图表，都能一键转成可编辑步骤，且编辑后的结果可反哺成新的 verified question（与机制 2 打通）。

### 机制 5｜场景模板中心 + 合伙人分销（抄九数云）
- **抄什么**：九数云把 300+ 场景模板（电商直播、大促库存、竞品售价、跨境、餐饮会员…）做成开箱即用货架，并开放"个人合伙人计划/伙伴联营"做分销〔事实〕。
- **我们怎么做**：先做 **10 个"一人公司"模板包**，每包固定结构 = 1 份演示数据 + 1 组指标（含口径/版本）+ 1 张仪表盘 + 3 个对话脚本（照着念就能演示）；每包单独定价（99–199 元）也可作为部署包赠品；分销激励：教程版学员推广返佣（先做手工对账，别上系统）。
- **验收**：模板包必须"导入即出图"，不允许需要客户改配置才能跑。

（备选第 6 个：**SmartBI 的 Skills 技能体系 + 工作流编排**——把报告/填报/归因/看板沉淀为可复用能力〔事实〕。我们对应的做法是把"清洗算子 + 洞察规则"打包成可复用的技能包，但这一条依赖清洗功能落地，放二期。）

3. **更新通道鉴权**：更新服务器只认有效 license；客服支持只对授权用户开放（用订单号绑定）。

## 5. 教程版：面向大学生的 10+2 章课程

### 5.1 设计原则（先说清为什么这样排）
- **每章必须产出一个"能给 HR 看的东西"**（图表、报告、指标定义、作品集页面），否则学生学完无法自证。
- **课程环境 = 我们的产品**：学生不是在 Jupyter 里算，而是在一个"有数据源、有指标、有权限"的真实工具里操作——**这本身就是"我们和 B 站免费课"的差异**。
- **每章埋一个"AI 会说错"的场景**：教学生核验 AI 结论，这既是我们产品的能力（可溯源），也是学生最缺的能力。

### 6.2 卖账号 / 代部署的数据合规
- **风险**：代部署会接触客户真实经营数据与数据库凭据；一旦泄露或被追责，后果远大于一单 2,800 元。
- **对策（写进交付确认单）**：
  1. 只用**只读账号**接入，最小权限；
  2. 交付完成后**删除我方持有的连接凭据**，并出具书面确认；
  3. **不留存、不导出、不用于演示**客户数据（演示一律用演示库）；
  4. 若必须接触个人信息字段，先脱敏或直接标为敏感列不参与分析（我们产品已有敏感列能力）；
  5. 代部署不代替客户做数据出境、等保、行业监管判断——**合同里写明责任边界**。
- **合同**：建议一份 1–2 页的简易"数据处理与保密条款"（谁处理、处理什么、多久删、违约怎么办），学生单与商业单分开。

### 6.3 学生数据隐私
- **风险**：学生作业里带真实姓名、学号、实习公司真实业务数据；录屏/批改会二次传播。
